# ✨ K/DA – Seletor de Personagens

Um site interativo de seleção de personagens inspirado no **K/DA**, o grupo pop virtual de League of Legends.

Este projeto permite que os usuários selecionem seus personagens favoritos do K/DA e alterem dinamicamente o nome, a imagem e a cor de exibição de cada um.

## 🚀 Funcionalidades

- Seleção interativa de personagens.
- Atualização dinâmica do nome do personagem.
- Alteração dinâmica da imagem do personagem.
- Cores personalizadas para cada personagem.
- Design moderno inspirado no universo K/DA.
- Integração com Google Fonts.
- Interface interativa utilizando JavaScript.

## 🛠️ Tecnologias Utilizadas

- **HTML5** – Estrutura do site.
- **CSS3** – Estilização, layout e efeitos visuais.
- **JavaScript** – Seleção interativa de personagens e atualização dinâmica de conteúdo.

## 💻 Como Executar o Projeto

1. Clone este repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

2. Abra a pasta do projeto.

3. Certifique-se de que todas as imagens estejam dentro do diretório `img`.

4. Abra o arquivo `index.html` no seu navegador.
